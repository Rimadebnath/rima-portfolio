# Rima Debnath Portfolio

Static portfolio website built with plain HTML, CSS, and JavaScript.

Live site: https://rima-portfolio-teal.vercel.app

## Structure

- `index.html` - semantic page markup
- `styles.css` - responsive visual system and layout
- `script.js` - navigation, reveal animation, and button interactions
- `assets/` - about section photos

## Deploy

This project is deployed on Vercel as `rima-portfolio`.
